# Rekanbot releases

Windows installers and auto-update metadata for **Rekanbot**, a desktop app for chatting with a team of AI agents powered by Claude Code.

Download the latest installer from the [Releases](https://github.com/mhanafi09051998/rekanbot-releases/releases/latest) page. Installed apps update themselves via the **Update** button in the sidebar.

This repository contains release files only; it holds no source code.
